## Hébergement

GitHub Pages, branche `main`, dossier `/ (root)`. HTML et CSS statiques, sans compilation, dépendance externe, JavaScript, outil d'analyse ni formulaire serveur. Les liens de contact ouvrent la messagerie du visiteur. `.nojekyll` désactive Jekyll.

## Maintenance

Modifier les pages anglaises et françaises ensemble. Actualiser la date de la politique en cas de changement. La politique repose sur les informations fournies par l'éditeur : Google AdMob, aucun achat intégré, pas de Firebase, pas de sauvegarde en ligne et jeu non destiné aux moins de 13 ans. Le code et la configuration du SDK n'ont pas été audités.

Avant la soumission du jeu :

- Ajouter dans le jeu un lien accessible vers la politique et le contact.
- Vérifier que les réponses App Privacy / Data safety reflètent la version et les réglages d'AdMob réellement intégrés. AdMob traite des données même sans Firebase.
- Vérifier les écrans de consentement, le retrait du consentement et l'autorisation ATT lorsque nécessaire. Une page web ne configure pas ces mécanismes dans le jeu.
- Si des comptes joueurs, un autre SDK ou un réseau de médiation sont ajoutés ou utilisés, compléter la politique pour les traitements correspondants et prévoir la suppression de compte lorsqu'elle est requise.
- Appliquer les engagements de conservation et de traitement des demandes décrits dans la politique.
